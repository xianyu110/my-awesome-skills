# 出海新词雷达

按「新词日更」方法，为出海工具站挖新词：三路采集、交叉验证、5 年核验、五重去重，再出中文日报。不要编造搜索量、难度、首页盘面或任何没有跑出来的数字。

## 何时使用

用户要挖海外/出海工具站新词、跑每日新词雷达、出日报，或提到 WhoisDS、Certstream、同行 sitemap、Google Trends Rising/Breakout、5 年核验时使用。

## 配套代码

本技能目录（`.claude/skills/xinci-radar/`）就是可运行的日更脚本：`run_daily.py`、`radar/`、`config/`、`certstream_listener.py`。本机若已有副本，优先复用现有项目目录，不要重新搭一套。不要把 SQLite、cache、密钥或任何 MCP/API token 提交进仓库或写进聊天。

## 怎么跑

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run_daily.py
# 复用当天已采集数据，只重跑交叉验证 / 5 年核验 / 报告：
.venv/bin/python run_daily.py --reuse --run-date YYYY-MM-DD
```

时区用环境变量 `RADAR_TZ`，默认 `Asia/Shanghai`。报告写到 `reports/YYYY-MM-DD.md` 和 `.html`。SQLite 在 `data/radar.db`，发布去重状态在 `data/published_state.json`。

可选证书透明日志监听（不阻塞日更）：

```bash
.venv/bin/python certstream_listener.py
```

需要能连上 `wss://certstream.calidog.io`。连不上就关掉，日更仍然只用 WhoisDS 免费日包。

## 三路采集

1. **域名**：WhoisDS 免费新注册域名日包 → 滤垃圾 → wordninja 切词根 → DNS + HTTP 探针。未解析域名保留为早鸟信号。已上线的抓 title / description，并探测定价页。核心词只取域名词根，不用网页 title 里的堆砌词。默认过滤上限 800、探针上限 320。
2. **同行 sitemap**：见 `config/sites.yaml`。按 lastmod 倒序收录，剥 `/es/` `/fr/` `/de/` 等语言重复路径。**lastmod 绝不当成关键词起量日。** 首次运行没有昨日快照，新增页为 0 是正常的，要把全量写入供下次对比。
3. **Google Trends**：`config/roots.json` 里 73 个工具站词根，5 个一批，时间窗 `today 1-m` 和 `now 7-d`，全球，收 Rising 与 Breakout。Breakout 再做一层二级下钻（默认最多 15 个二级种子）。响应先切掉 XSSI 前缀 `)]}'` 再解析 JSON。批次间隔 2–3 秒，遇 429 退避。若 HTML 探索页 429，可先访问 trends.google.com 拿到 NID cookie 再调接口。相关查询必须带上种子词根、长度为 2–6 词、且不是句子，才进入候选。

## 交叉验证

- 两路及以上命中进重点池，单路进观察池。
- 停放页、品牌杂音丢弃。
- 交叉匹配要严，不要因为泛词（如健身、并购新闻）就当成工具机会。
- 用正则滤掉模型版本号。
- 不够 20 条不要硬凑，报告如实写过了几条。

## 5 年核验

- 候选词必须单独拉 `today 5-y`（约 262 周），不得和大词打包。
- 没有可用 5 年序列的词，不能进入关键词板块。
- `has_data=false` 的周按 0 计入底盘均值，不能只平均非零周，否则稀疏新词会被误判成长青。
- 默认每天最多核验 40 个词，优先重点池和 Breakout。观察池里没核验的词，不要写成已分类新词。
- 分类规则：
  - **纯血从零突发**：5 年均值 ≤ 2，非零周 ≥ 1，首次非零周在约 18 个月内，年度峰少于 3 个，且近期有拉升（近 8 周峰值 ≥ 20，或达到序列峰值的一半且 ≥ 40）。
  - **年度周期回潮**：至少 3 个年度峰。
  - **长青老词翻红**：均值在 20–70，只标注，不当首次爆发。
- 若首次非零周正好是 5 年窗口的第一周，只能说明更早就有搜索，不能当成首次出现日。

## 五重去重

对照 `data/published_state.json`：

1. 字符归一化后完全相同。
2. 去掉 ai / free / online / tool 等虚词后，实义词 Jaccard ≥ 0.5 且交集不少于 2 个词。
3. 按 `config/synonyms.json` 展开同义词后再做同样的 Jaccard。
4. 域名词根与已发布词双向子串（长度至少 5）。
5. 报告写完后，把本批已发布词和域名回填进 JSON。

## 写报告

用中文写日报。只写有证据的词：命中了哪路信源、5 年统计、Trends 关系（Rising / Breakout 与涨幅）、相关域名及探针状态。新闻、影视、游戏向的词可以列入，但要标明不一定适合做成工具站。长青老词单独标注，不要写成新词爆发。

## 与关键词库交叉核验（可选）

若已连接哥飞 SEO / WebCafe SEO 一类词库：

- 只用免费的新词库、批次和搜索工具对照今日报告中的词。
- 不要编造难度、搜索量或首页竞争盘面。
- 开放接口的付费工具（难度、搜索量、SERP 精评、选词手册）在积分余额为 0 时不要重试；说明原因，并给出服务方公开的充值入口。
- 若每日赠送额度只适用于网站、不适用于开放接口，要如实写。
- 结论要区分：两边判断一致、词库已判不建议做、雷达先扫到但词库尚未收录。没有数据就说没有数据。

## 硬性约束

- 所有采集数字、分类和域名状态必须来自实际运行或工具返回，禁止编造。
- 保持对 73 个词根、5 年单独拉取、不足 20 条不补齐等断言，不要为了好看而放宽。
- 不要把 token、Cookie、数据库或 cache 写进技能、聊天或 Git 仓库。
- 不要卸载已连接的 SEO 接口来「修复」它；用原服务名和正确鉴权更新即可。
